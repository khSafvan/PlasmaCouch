# PlasmaCouch Fork Information

## Origin
PlasmaCouch was forked from KDE Plasma Bigscreen (master branch, Plasma 6 / KF6 era).

## Purpose of this Fork
PlasmaCouch expands upon the TV/controller shell foundation to create a unified 10-foot media and game launcher capable of launching:
1. Native Linux Applications
2. PWA / Web Applications
3. Windows games and applications via Wine / Proton
4. Android applications via Waydroid
5. Console emulators and game libraries

## Upstream Changes & Modifications
- Re-branded to PlasmaCouch with independent `com.plasmacouch.*` application and D-Bus namespaces.
- Hardened shell session scripts, environment handling, and D-Bus integration.
- Added automated quality checks, verification runner, and modernized ECM/CMake configuration.
- Scaffolding and roadmap for multi-source app launching.
